同主题但材料不同的限行、合租、城市艺术、快餐、售货机、电子游戏、儿童科技分别处理。狩猎材料2为动机分类，未被误写成无条件赞成；简历照片材料基本一致；广告材料2补充家庭和社会因素。

- `work-checkpoint.json`：完整源记录、来源、哈希与断点状态。
- `exams-2026-07-10.json` / `exam-data.js`：36组映射，45条完整原文，32篇四段双语迁移稿，材料摘要、立场、来源及新增记忆词形统计。
- `matching-audit.md`：逐任务匹配核对。
- `study-ui.js` / `study.css`：增量学习功能。
- `tools/`：可重复生成的迁移配置及脚本。于仓库根目录运行 `node tache3-exams/tools/build-exams.cjs`。
- `tests/verify.cjs`：数据和学习交互验证。需要 Node.js 和 jsdom（测试环境依赖，不参与网页部署）。

原有 `data.js` 和 `translations.js` 未改。原学习键 `tcf-writing-trainer-v1` 与原单词本键保留。新增原稿注释独立存于 `tcf-writing-trainer-v1-reference-annotations-v1`，按文章ID和段落索引绑定。直接匹配稿沿用原文章ID与学习状态；迁移稿只出现在真题模式中。

字数按空格分词计算，法语撇号及连字符组成的词不拆开，所有真题模式答案均为120–180词。新增记忆统计按整套62篇的法语词形比较，包含变形；该数量不是词汇难度或熟练度评分。主题词汇来自人工整理的名词清单，仅展示当前文章中出现的项。
